# Node L3 route admission and applied status

- **status**: completed
- **createdAt**: 2026-10-23 04:50
- **approvedAt**: 2026-10-23 04:50

## Context

NodeL3Authority already fixes full identity/key bindings and complete policy bytes.
SubnetPublication independently derives selected real destinations and proxy coverage.
The normalized profile incorrectly groups provider route destinations with host identities.
PublicationEvent retains the exact signed inner bytes; SourceBinding owns source fencing.
MaterialStatusResponse supplies an existing exact report echo pattern.

## Proposal

Correct mapped route admission independently of direct host rules. Specify the exact
confidential status request, signed-event digest, retained-context comparisons and receipt.
Produce independent Python vectors before implementing pure Rust codecs and comparators.
Preserve NodeL3, grants, Subnet and service-control bytes; add no runtime or I/O.

## Scope

Protocol account module, independent vector producers and consumers, profile,
grant specification, review request and family state documentation.

## Risks

A same-version different event or replaced source must never establish current evidence.
Receipt confirms transport only; empty Applied confirms removal and cannot grant access.
Authentication and retained authority must come from independent caller inputs.

## Acceptance

- Independent route vectors distinguish selected mapped destinations from direct hosts.
- Independent status vectors fix digest, request, receipt and refusal bytes.
- Exact retained event and every source field fence reports in both directions.
- Formatting, lint and the scoped repository self-check pass.

## Alternatives

Reuse the existing domain digest and envelope contracts without a runtime adapter or
legacy acknowledgement compatibility layer.
