# HYG-001 Commit lockfile for reproducible QA

- **status**: completed
- **priority**: P1

## Description

Make the ns-shared dependency graph reproducible for the local QA gate. The
workspace currently runs cargo-deny as part of `just qa`, but `Cargo.lock` is
ignored and therefore fresh checkouts can resolve a different dependency graph.

Acceptance criteria:

- `Cargo.lock` is tracked in git.
- Cargo-based QA commands assert that the lockfile is unchanged.
- The checked-in lock resolves `time` to a non-yanked current version and
  `quinn-proto` to the current 0.11 patch release.
- Focused supply-chain verification passes with the locked graph.

## ActiveForm
