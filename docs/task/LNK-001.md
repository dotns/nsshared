# LNK-001 Activate non-future V1 WgRelay leases immediately

- **status**: in progress
- **priority**: P0
- **owner**: plan-121-coordinator
- **createdAt**: 2026-07-17
- **plan**: ns PLAN-121

## Description

Update the existing V1 WgRelay receipt-anchored deadline translator without
changing any wire field or function signature:

- map `not_before <= signed_at` to immediate usability at raw-frame receipt;
- preserve the guarded future-barrier calculation when
  `not_before > signed_at` for old NSD rolling compatibility;
- retain conservative monotonic hard expiry, all signed interval bounds, typed
  failures, and `NoUsableWindow` for the legacy future-barrier path.

This task is based on ns-shared `main` and is independent of Config Stream V2.

## ActiveForm

Removing the avoidable V1 activation guard for already-non-future leases.

## Dependencies

- **blocked by**: PLAN-121 approval
- **blocks**: ns LNK-025; nsgw LNK-016

## Acceptance

- Both `not_before == signed_at` and `not_before < signed_at` produce
  `not_before == received_at`.
- A 300-second signed interval retains receipt plus 235 seconds as its
  conservative monotonic hard expiry.
- A legacy future barrier retains the existing 65-second activation guard and
  can still produce `NoUsableWindow` for consumer quarantine.
- Non-positive, overlong, and overflowing intervals remain typed failures.
- Public wire types, constants, and function signatures remain unchanged.
- Focused tests, formatting, strict Clippy, and crate tests pass.
