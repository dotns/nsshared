## Description

Implement the approved quick invite/join flow across ns, nsgw and ns-shared.
Use a stable two-letter relay directory key and eight random digits. Preserve
existing identity, admission and data-plane behavior and the account runtime.
Require explicit peer confirmation; do not turn a short code into a bearer
credential. Bound and clean temporary state after cancellation, denial, expiry
and completion, with bounded recovery for uncertain delivery.
