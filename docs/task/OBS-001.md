# OBS-001 Add proxy path labels

- **status**: completed
- **priority**: P1
- **owner**: proxy-otel-path-label
- **createdAt**: 2026-06-13 00:00

## Description

Add the bounded `path` label (`tun`, `userspace`, `wss`) to the shared
`telemetry::proxy_otel` facade so proxy metrics can distinguish the data-plane
path while keeping the existing metric names.

Acceptance criteria:

- `telemetry::proxy_otel::*` metric helpers require a `telemetry::labels::Path`
  argument and emit `LABEL_PATH`.
- `tunnel-ws` records WSS relay proxy metrics with `Path::Wss`.
- The sibling `ns` workspace migrates its UserSpace relay call sites to
  `Path::Userspace`.
- Tests in both workspaces assert the new `path` label on proxy metrics.
- TUN mode is documented as a label value but does not emit fake proxy metrics,
  because TUN traffic is handled by kernel/NAT rather than a proxy relay loop.

## ActiveForm

Adding a bounded `path` label to shared proxy OTel metrics and coordinating the
live `ns` consumer migration.
