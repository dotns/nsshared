# DNS-001 Define canonical internal DNS helpers

- **status**: completed
- **priority**: P0
- **owner**: BKD sd8cx1z2/f8kq3s0o
- **createdAt**: 2026-06-17 11:27

## Description

Define canonical NSIO internal DNS suffix constants and formatting helpers in the
shared `common` crate. Downstream repositories must use this API instead of
hard-coded `.n.ns`, `.m.ns.io`, or `.gw.ns.io` literals in behavior paths.

Acceptance criteria:

- `common` exposes canonical service, machine, and gateway suffix constants.
- `common` exposes helper functions for service, machine, gateway FQDN generation
  and canonical suffix checks.
- `ServiceDef::fqid()` uses the canonical service helper and returns
  `<service>.<site>.n.ns.io`.
- Machine registration state documentation/tests align with `<machine_id>.m.ns.io`.
- No runtime behavior in `common` formats `.n.ns` service names directly.

Legacy `.n.ns` alias generation and compatibility resolution are explicitly out
of scope for this change.
