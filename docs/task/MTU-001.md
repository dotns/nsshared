# MTU-001 Define the shared WireGuard plaintext MTU default

- **status**: completed

## Description

Define one shared WireGuard plaintext-MTU default of 1360 bytes so NS and
NSGW consumers cannot silently drift. This is a local data-plane default, not
a wire field or control-plane projection.

Acceptance criteria:

- `common` exports the canonical 1360-byte default.
- The constant is usable by both `ns` and `nsgw` without a dependency cycle or
  an external dependency.
- Existing explicit MTU overrides and the supported plaintext buffer ceiling
  remain separate from the default.
- Focused tests and repository quality gates pass.

## ActiveForm

Defining the shared WireGuard plaintext MTU default.
